# Week 2 – Beginner Python Programming

This folder contains the Python programs completed for Week 2 of the AI-Native Python Programming Internship.

## Projects

### 1. Profile Card
A simple Python program that collects basic information from the user and displays it as a profile.

### 2. Age Calculator
A simple program that calculates a user's age from their year of birth.

### 3. Unit Converter
A Celsius-to-Fahrenheit temperature converter.

### 4. Receipt Total Calculator
A simple receipt calculator that calculates the total cost of an item based on its price and quantity.

### 5. Simple Interest Calculator
A program that calculates simple interest and the total amount after interest.
