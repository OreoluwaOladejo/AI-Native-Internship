# Week 5: Python Utility Program

## Project Overview
This project refactors my WEEK 3 Python program into reusable functions and separates the program's logic into different files.
The program provides three main features: a calculator, a Celsius-to-Fahrenheit converter, and an even/odd number checker.
The project demonstrates the use of functions, parameters, return values, variable scope, imports, input validation, and basic Python code-quality conventions.

## Project Features
1. **Calculator:** Performs addition, subtraction, multiplication, and division.
2. **Temperature Converter:** Converts temperatures from Celsius to Fahrenheit.
3. **Decision Maker:** Checks whether a number is even or odd.
4. **Input Validation:** Handles invalid numeric inputs and invalid menu choices.
5. **Error Handling:** Prevents division by zero.
6. **Reusable Functions:** Organises repeated logic into functions that can be called when needed.


## How to Run the Program
1. Open a terminal in the `Week 5` directory.
2. Run the following command:
   ```bash
   python main.py
   ```
3. Follow the instructions displayed in the terminal.
4. Select an option from 1 to 4 to use a feature or exit the program.

## Conclusion

This project demonstrates how a beginner Python program can be refactored into a more organised, readable, and reusable structure while preserving its original functionality.
