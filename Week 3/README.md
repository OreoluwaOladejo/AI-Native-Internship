# Week 3 — Project 1: Number & Decision Toolkit

## Overview
A menu-driven command-line program that combines a calculator, a 
Celsius-to-Fahrenheit converter, and an even/odd decision checker. 
The program loops until the user chooses to exit.

## Features
- **Calculator**: performs addition, subtraction, multiplication and 
  division on two numbers (handles division by zero and invalid input)
- **Converter**: converts a temperature from Celsius to Fahrenheit
- **Decision Checker**: tells the user whether a number is even or odd
- Menu loops until the user selects option 4 to exit
- Invalid menu choices and invalid number input are handled without crashing
