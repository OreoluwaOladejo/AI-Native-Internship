# Week 4: Collections and Data Organisation

## Overview
This folder contains two Python programs that practise lists, tuples, sets and dictionaries:
1. **Contact Book** (`contact_book.py`)
2. **Student Scores** (`student_scores.py`)

## Files
- `contact_book.py`: a program for managing contacts
- `student_scores.py`: a program for recording and analysing student scores




## Exercise 1: Contact Book
**What it does:**
- Add a new contact
- Update an existing contact
- Remove a contact
- Search for a contact by name


**Collections used:**
- **Dictionary:** stores contacts, with each name as the key
- **Set:** . checks for duplicate phone numbers
- **Tuple:**  holds fixed contact details
- **List:**  stores the list of contacts to display

## Exercise 2: Student Scores
**What it does:**
- Add a student and their scores
- Update or remove a student's records
- Show a student's scores
- Calculate total and average scores
- Sort students by score


**Collections used:**
- **Dictionary:** stores each student's name and their scores
- **List:** stores the scores for each student
- **List comprehension:**  filters passing scores
